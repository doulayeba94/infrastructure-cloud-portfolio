# Plateforme cloud de partage de fichiers (T3)

Hébergée sur le site "datacenter" (simulant l'hébergeur cloud).

Fonctionnalités attendues :
- Partage de fichiers via lien web
- Consultation d'un fichier en ligne via navigateur
- Groupes de partage avec droits d'accès
- Client de synchronisation local
- Synchronisation régulière vers Londres (PCA) + copie prête à démarrer sur le site PRA
